# OpsQuill

A collection of **Shell scripts** and **Python automation tools** for automating common DevOps tasks.

This repository focuses purely on **automation** - helping engineers reduce the time spent on repetitive server tasks that are also prone to manual errors. Opsquill converts these routine operations into simple, dependable scripts that behave consistently and can be used across different environments.  

Built for anyone looking to simplify their daily operational work, this project is useful whether you want ready-to-use scripts or examples to learn from.
> It will continue to grow over time with more automation tools.

---

## 📌 What's Inside

- **[Python Scripts](./python-scripts)** - Python-based automation tools for DevOps workflows
- **[Shell Scripts](./shell-scripts)** - Bash scripts to automate repetitive DevOps tasks

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/sharadverma638/sv-opsquill.git
cd sv-opsquill
```

Make shell scripts executable before running them:

```bash
chmod +x shell-scripts/<script-name>.sh

./shell-scripts/<script-name>.sh     # Run Shell Scripts
```

Run Python scripts:

```python
python3 python-scripts/<script-name>.py
```

- Bash shell
