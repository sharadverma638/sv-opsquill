# Opscripts

A collection of **Shell scripts** and **Python automation tools** built to simplify and automate day-to-day **DevOps operations**.

This repository focuses purely on **automation** - helping engineers save time on repetitive tasks like server management, monitoring, deployments, and troubleshooting.
> It will continue to grow over time with more automation tools.

---

## 📌 What's Inside

- **Shell Scripts** - Bash scripts to automate repetitive DevOps tasks
- **Python Scripts** - Python-based automation tools for DevOps workflows

---

## 📂 Repository Structure

```
sv-opscripts/
├── shell-scripts/        # Bash automation scripts
├── python-scripts/       # Python automation tools
└── README.md
```

---

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/sv-opscripts.git
cd sv-opscripts
```

Make shell scripts executable before running them:

```bash
chmod +x shell-scripts/script-name.sh
./shell-scripts/script-name.sh
```

Run Python scripts:

```python
python3 python-scripts/script-name.py
```

- Bash shell
